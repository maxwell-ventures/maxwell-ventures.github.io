# astrojaacks.com

Personal portfolio for Jason Jaacks — serial builder, curious mind, wanderer.

A single, self-contained static page (no build step) served via GitHub Pages.

- `assets/shots/` — optimized project screenshots
- `play/nomnom/` — playable build of NOM NOM TOKENS
